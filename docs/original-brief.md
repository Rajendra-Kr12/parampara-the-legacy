#This is the a detailed plan about paramapara_the_legacy
Built as a mobile app as well as web app

#The Idea
The goal of Parampara app is to store the family legacies even after marriages, create family trees of both maternal and paternal sides and create and establish and rekindle connections and also map relatives in the same city and also any family friends, well wishers etc.

1. Parampara is a family based app where it offers user to map his relatives and extended family persons or his previous generations
2. The user should register and login and create his profile
3. The user should be able to invite their family persons and while inviting either mention thier known relation or ask the person invited to disclose his relation with the invitee. you can not register without a disclosed relationship and this relation should be verified by the invitee.
4. The user can add profiles for the deceased people. Profile of such people should have a status approved or rejected in the generation.. I mean atleast 3 people should approve
5. The user can add stories about thier known interactions with their family. I think this can be categorized as memories and stories. Memories are thier own personal expereinces.. Sstories should be approved by a some closest relatives in the family. For example.. A user's father adding a memory about deceased grandfather can be accepted, but a story about the grand father should be verified by either thier by alive person, i.e grandmother, uncles or aunts.
6. Relations are majorly focused towards like local indian relation things like "Atta" "Menattah", "Nanamma", "Tatayya"
7. If a relation map is conflicted from mother side and father side due to congenial marriages, father side is preferred and mother side relatioon is taken optional.. or sometime user can be given choice how they want to tag thier own..
8. The profile should contain Name, DOB, phone number, current address, if not last known address. Name is mandatory.. DOB is manadatory and if not know at least we need the year, current address is mandatory.. but if they are adding by themselves, last known address is needed.
9. If some one creates a prfile on behalf of someone else.. the phone number invite is mandatory for registration or email invite.. so that they can register through that link and verify properly.
